# Online Examination System

A web-based online examination system developed using Python and Streamlit.

## Features

- Student name entry
- Multiple-choice questions
- Online exam interface
- Automatic answer evaluation
- Score calculation
- Result display

## Technologies Used

- Python
- Streamlit
- JSON

## How to Run

1. Install the required packages:
   `pip install -r requirements.txt`

2. Run the application:
   `streamlit run app.py`

## Project Purpose

This project demonstrates the development of a simple online examination platform with automated evaluation and result generation.
